# Project Wildcard

A digital adaptation of **Clear the Dungeon** — a solo card game by [The Lone Cardman](https://youtu.be/GbEkAfCqfTM).

## About the Game

Clear the Dungeon is a single-player card game where you battle through a dungeon grid of face cards using attack cards from the rest of the deck.

**Setup:** The deck is split into two piles — attack cards (number cards, aces, and jokers) and monster cards (jacks, queens, kings). The monsters are laid out in a 4×3 grid: the first two rows face down, the third face up.

**Card values:** Ace = 1, number cards = face value, Jokers = wild (up to 10), Jack = 11, Queen = 12, King = 13.

**How to play:** Draw three attack cards per turn. To eliminate a monster, play two attack cards whose combined value meets or exceeds the monster's value, then finish the attack with a *trigger card* — a third card matching the suit of the face card. Used attack cards go to a discard pile and cannot be reused.

**Win condition:** Clear all face cards from the dungeon before running out of attack cards. Games typically come down to the last few draws.

> The combo + trigger mechanic was inspired by *Grid Cannon*.

## Concept

The rules are based on the physical card game shown above — this project brings it to a digital format built in Godot.
