# Project Wildcard

A digital adaptation of **Clear the Dungeon** — a solo card game by [The Lone Cardman](https://youtu.be/GbEkAfCqfTM).

## About the Game

Clear the Dungeon is a single-player card game where you battle through a dungeon grid of face cards using number cards from the rest of the deck.

**How to play:** Draw three number cards per turn. To eliminate a monster, play two number cards whose combined value meets or exceeds the monster's value, then finish the attack with a *trigger card* — a third card matching the suit of the face card.

**Win condition:** Clear all face cards from the dungeon before running out of attack cards. Games typically come down to the last few draws.

**Card values:** Ace = 1, number cards = face value, Jokers = wild (up to 10), Jack = 11, Queen = 12, King = 13.
