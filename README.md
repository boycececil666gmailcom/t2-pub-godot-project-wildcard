# Project Wildcard

A digital adaptation of the card game demonstrated in [this tutorial](https://youtu.be/GbEkAfCqfTM).

## Concept

The rules are based on the physical card game shown above — this project brings it to a digital format built in Godot.

> **Note:** The source code for this project has been lost. The repository is kept for reference and the demo remains playable on itch.io.
